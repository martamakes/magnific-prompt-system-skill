# Magnific prompt system (skill)

Skill de Claude Code **solo de redacción** para preparar producciones audiovisuales con IA: te entrega prompts listos para pegar en [Magnific](https://www.magnific.com) (imagen con Nano Banana, vídeo con Seedance). No genera imágenes, vídeo ni audio, y no gasta créditos: nada se genera sin orden expresa (`references/reglas.md` §13).

Este repo es la release instalable de la skill.

## Instalación

```bash
# todos tus proyectos
git clone https://github.com/martamakes/magnific-prompt-system-skill ~/.claude/skills/magnific-prompt-system
# o solo un proyecto: <proyecto>/.claude/skills/magnific-prompt-system
```

También puedes descargar el zip de la release y descomprimirlo en esa carpeta. Abre una conversación nueva y escribe: `Oye Amenábar, ¿en qué fase estoy?`

Guía de uso: `references/guia-usuario.md`. Los límites de modelos (`references/modelos.md`) son borradores que debes contrastar con tu cuenta.
